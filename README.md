# LiBot: Autonomous Library Robot for Book Search & Bookshelf Inventory Management

## Overview
Traditional library management faces significant challenges in keeping inventory records accurate and assisting readers in navigating large facilities[cite: 1]. Manual bookshelf audits are labor-intensive, time-consuming, and highly prone to human error—often leading to misplaced or missing books[cite: 1]. **LiBot** is an integrated autonomous robotics and software ecosystem designed to automate bookshelf inventory audits and deliver interactive navigation assistance for readers and staff[cite: 1].

## Key Capabilities

* **Autonomous Navigation & Guiding:** Navigates independently using predefined indoor maps and real-time obstacle avoidance[cite: 1]. Guides readers directly to target bookshelves or library facilities (e.g., circulation desks, reading areas)[cite: 1].
* **Automated Bookshelf Inventory:** Scans barcodes along shelves, compares scanned data against the library database in real time, identifies misplaced or missing items, and compiles comprehensive inventory reports[cite: 1].
* **Interactive Reader Service:** Readers can query books via title, ISBN, author, or category through the robot’s onboard display or client applications, view real-time availability, and request physical routing[cite: 1].
* **Staff Operations & Task Dispatch:** Librarians can remotely assign inspection and inventory routines, monitor robot status in real time, and receive instant alerts regarding out-of-order books or anomalies[cite: 1].
* **Centralized Administration:** Provides role-based access control, book catalog and digital map management, robot hardware profiling, operational logs, and system analytics[cite: 1].

## Architecture & Technology Stack
* **Backend:** .NET Web APIs, Cloud Infrastructure (AWS / Azure)[cite: 1]
* **Database:** Relational Database (SQL Server / MySQL)[cite: 1]
* **Client & UI:** ReactJS (Web Admin/Librarian Portal), Flutter (Mobile Clients)[cite: 1]
* **Robotics:** Autonomous navigation, path planning, and barcode scanning modules[cite: 1].
