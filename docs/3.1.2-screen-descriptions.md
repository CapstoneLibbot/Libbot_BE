#### *3.1.2 Screen Descriptions*

*The table describes the screens currently implemented in LibBot Mobile and LibBot FE. Route aliases and redirect paths are grouped with their target screen.*

| **#** | **Feature** | **Screen** | **Description** |
| ----- | ----------- | ---------- | -------------- |
| 1 | Reader kiosk | Idle / Welcome (`/(kiosk)/idle`) | Shows the kiosk welcome screen and provides the starting point for readers. |
| 2 | Find books | Book Search (`/(kiosk)/search`) | Lets readers search the book catalog and select a book to view more information. |
| 3 | Find books | Book Detail (`/(kiosk)/catalog/:bookId`) | Shows book information, availability, and the book location in the library. |
| 4 | Guide readers | Guidance Map (`/(kiosk)/guidance/map`) | Shows the guidance screen for the selected book or library destination. |
| 5 | Guide readers | Guidance Mission (`/(kiosk)/guidance/:missionId`) | Loads a guidance mission and displays its current progress to the reader. |
| 6 | Guide readers | Facility Search (`/(kiosk)/facilities`) | Lets readers search for library areas and facilities. |
| 7 | Guide readers | Facility Detail (`/(kiosk)/facilities/:facilityId`) | Shows information about a selected library area or facility. |
| 8 | Guide readers | Facility Guidance (`/(kiosk)/facilities/:facilityId/guidance`) | Starts guidance from the kiosk to the selected library area or facility. |
| 9 | Reader feedback | Guidance Feedback (`/(kiosk)/feedback/:missionId`) | Lets the reader submit feedback after a guidance mission. |
| 10 | Kiosk settings | Settings (`/(kiosk)/settings`) | Provides settings and return controls for the kiosk application. |
| 11 | Dashboard | Overview (`/`) | Shows an overview of library operations and links to the main management functions. |
| 12 | Map and robot management | Map List (`/maps`) | Lists available library maps and provides access to map management actions. |
| 13 | Map and robot management | Create Map (`/maps/create`) | Provides a form for creating a library map. |
| 14 | Map and robot management | Robot Map Detail (`/maps/:id`, `/maps/robot/:id`) | Displays a selected map with robot position and operation information. |
| 15 | Library structure | Floor List (`/floors`) | Lists the floors configured for the library. |
| 16 | Library structure | Floor Detail (`/floors/:id`) | Shows the details and related areas of a selected floor. |
| 17 | Library structure | Aisle Detail (`/aisles`, `/aisles/:id`) | Displays aisle information and the related shelf structure. |
| 18 | Library structure | Shelf List (`/shelf`, `/shelves`) | Lists shelves used to organize books in the library. |
| 19 | Library structure | Shelf Detail (`/shelves/:id`) | Shows shelf information and its book location data. |
| 20 | Book management | Book List (`/book`) | Lists books and supports access to book search and management actions. |
| 21 | Book management | Book Detail (`/book/:id`) | Shows the details, status, and location of a selected book. |
| 22 | Borrowing and returning books | Book Transactions (`/book-transactions`) | Provides the main screen for managing book issue and return transactions. The aliases `/circulation`, `/transactions`, `/receipts`, and `/issues` open this feature. |
| 23 | Borrowing and returning books | Create Receipt (`/book-transactions/receipts/new`) | Creates a book return receipt and records books returned to the library. |
| 24 | Borrowing and returning books | Receipt Detail (`/book-transactions/receipts/:id`) | Shows the details and status of a book return receipt. |
| 25 | Borrowing and returning books | Create Issue (`/book-transactions/issues/new`) | Creates a book issue record and records books borrowed from the library. |
| 26 | Borrowing and returning books | Issue Detail (`/book-transactions/issues/:id`) | Shows the details and status of a book issue record. |
| 27 | Automatic inventory | Inventory Scan (`/inventory`) | Starts and manages an inventory task for checking books and shelf locations. |
| 28 | Automatic inventory | Inventory Results (`/inventory-results`) | Displays inventory results, including scanned books and detected inventory issues. |
| 29 | Robot task management | Task List (`/tasks`) | Lists robot tasks and shows their current statuses. |
| 30 | Robot task management | Dispatch Workflow (`/dispatch`) | Selects and dispatches a workflow for a robot task. |
| 31 | Robot task management | Create Task (`/tasks/create`) | Creates a robot task, including a library patrol or inventory mission. |
| 32 | Robot task management | Task Detail (`/tasks/:id`) | Shows task information, status, and available task actions. |
| 33 | Workflow management | Workflow List (`/workflows`) | Lists workflows available for robot operations. |
| 34 | Workflow management | Create Workflow (`/workflows/create`) | Creates a workflow with the steps required for a robot operation. |
| 35 | Workflow management | Workflow Detail (`/workflows/:id`) | Shows the details and configuration of a selected workflow. |
| 36 | System navigation | Alerts (`/alerts`) | Displays the current alerts route. The page is a placeholder in the current FE implementation. |
| 37 | System navigation | History (`/history`) | Displays the current history route. The page is a placeholder in the current FE implementation. |
| 38 | System navigation | Reports (`/reports`) | Displays the current reports route. The page is a placeholder in the current FE implementation. |
| 39 | System navigation | Settings (`/settings`) | Displays the current management settings route. The page is a placeholder in the current FE implementation. |
